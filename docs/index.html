Grupo de servidores tolerante a falhas com serviço de xadrez

Um grupo de servidores mantém uma mesma partida de xadrez no ar usando sockets UDP e multicast IP. Cada servidor anuncia que está vivo por heartbeat, o servidor vivo de menor UID atua como líder, e as demais réplicas recebem o tabuleiro a cada lance. Se o líder cair, o próximo menor UID assume.

Como executar

É necessário Python 3 e a biblioteca de xadrez. Primeiro, crie o ambiente virtual e instale a dependência:

python3 -m venv .venv
source .venv/bin/activate
pip install chess

TODO: o README manda usar pip install -r requirements.txt, mas esse arquivo não existe no repositório. O comando acima usa o pacote citado no próprio README. A versão da biblioteca não está fixada.

Depois, em terminais separados e com o ambiente ativado, inicie os servidores e o cliente:

python3 servidor.py 1
python3 servidor.py 2
python3 servidor.py 3
python3 cliente.py

O argumento do servidor é o seu UID. Os lances usam o formato UCI, como e2e4 ou g1f3, e sair encerra o cliente.

Para testar a tolerância a falhas, pressione Ctrl+C no líder (o servidor de menor UID) no meio da partida e espere cerca de 4 segundos para que os outros servidores detectem a saída dele.
