\subsection*{\textbf{Heartbeat}}

Na segunda parte do dia fizemos uma comunicação heartbeat entre os servidores da rede a fim de todos terem a consciência de quais servidores ainda estão conectados na rede a cada 1 segundo, período de tempo estabelecido por nós. Tivemos que importar uma biblioteca específica do Python (\textbf{threading}) para ter duas ou mais funções executando ao mesmo tempo, isso é, tanto a comunicação entre cliente e servidores quanto o heartbeat dos servidores rodando juntos.

Para essa parte do projeto foram necessárias algumas funções e estrutura de dados extras. Em primeiro lugar, cada servidor deve ter uma tabela consigo guardando a informação de quem ainda está ativo na rede e quem não está mais. A estrutura de dados que escolhemos para isso foi um dicionário, em que funciona basicamente como uma estrutura de dados 'chave-valor'. Ademais, precisou-se de funções adicionais para guardar o valor dos UIDs de cada servidor nesse dicionários locais. Finalmente, implementamos uma última função extra para consultar o tempo do último heartbeat mandado pelo servidor e o tempo atual, com o intuito de remover da tabela local os servidores mortos.

Portanto, a lógica final do heartbeat foi chamar essas funções de pegar o UID, atualizar a tabela e conferir o tempo atual com o último sinal enviado em uma das threads rodando, chamada de background em nosso código.
